## 1. 方針

解析と品数は Vitest の表駆動単体テスト、画面は Playwright の mobile / desktop で確かめる。性能は既存の CPU 4 倍模擬と CI の判定方針に従う。実装時に各ケースを具体化し、既存テストを維持する。
