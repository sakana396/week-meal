## 1. 方針

- 単体テストは Vitest で書き、`src/**/*.test.ts` に置く
- テストケース ID は `TC-<要求ID>-<連番2桁>`。テストの名前（`it` の第 1 引数）の先頭に ID を書く
- 1 つの要求に、正常系・境界値・異常系を最低 1 件ずつ考える
- 計算の期待値は手計算で求め、計算の過程を備考に書く（NFR-15）
