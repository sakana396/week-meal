## 1. 方針

分けた食材名と言い換えの表は `src/data` の定義データ、当てはめは `src/core` の純粋な関数として、Vitest の表駆動テストで確かめる（NFR-08、NFR-11）。画面は Playwright の mobile / desktop で確かめる。性能の時間超過は CI では記録のみ、計測不能・機能不整合は失敗とする（TST-IT05 1 章のまま）。既存のテストは消さない。分けた食材名で期待値が変わった既存のケースは、3 章に ID と理由を書く。炭水化物の調査（DES-IT06 4 章）は調査記録で扱い、テストケースは作らない。
