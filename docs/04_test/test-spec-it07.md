## 1. 方針

製品の既存のテストと期待値は変更しない。本仕様は、実際の買い物による手動検証と調査結果を確認する項目を定める。下のケースは未実施であり、コードに実装済みのテストケースではない。製品の自動テストの成功を H-17・H-18 の実地検証結果に置き換えない。

本人が示したデータを受け取るまで実地検証・再計算は未実施とする。対象の表記・食品がなければ、その仮説は未検証。データ不足や境界のケースを架空の本人の買い物として作らず、実際の入力で該当するときに確認する。具体的な栄養値は入力が揃ってから照合の根拠とともに記録する。
