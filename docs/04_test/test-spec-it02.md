## 1. 方針

- 単体テストは Vitest（`src/**/*.test.ts`）、E2E テストは Playwright（`e2e/*.spec.ts`）で書く
- テストケース ID は `TC-<要求ID>-<連番2桁>`。反復 1 の連番の続きから振る（例: TC-FR-ING-10-01 は新規、TC-FR-ING-09-08 は反復 1 の続き）
- E2E のテストの名前にも ID を書き、スマートフォン幅（mobile、360×740）と PC 幅（desktop、1280×800）の両方で実行する（`npm run test:e2e`、DES-E2E）
- 1 つの要求に、正常系・境界値・異常系を最低 1 件ずつ考える
