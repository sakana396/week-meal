## 1. 方針

`src/core/` の量の換算・切り替え・保存の移行・指示文・読み取り・一括登録は、Vitest の表駆動テストで入力不変と分岐を確かめる。画面は Playwright の mobile / desktop で確かめる。性能の時間超過は CI では記録のみ、計測不能・機能不整合は失敗とする。既存のテストは消さない。`count` を `quantity` に置き換えて期待値を変えたケースは、3 章に旧ケースと理由を書く。
