## 2. 製品の狙い

| # | 発言の要旨 | 解釈 |
|---|---|---|
| E-03 | 「簡単入力のみで管理する」を目標にする | 最上位の目標。入力の手間を最小にすることが、ほかのすべてより優先される |
| E-04 | スコープは自炊 | 外食・コンビニ食・中食は対象外 |
| E-05 | 既存アプリは外食・コンビニ食に注目している | 競合との差別化の軸は「自炊」 |
| E-06 | そのため既存アプリは 1 食ごとの入力になる | 1 食ごとの記録は、本アプリが避けたい手間の典型 |

| E-08 | 自炊の場合、複数日分の食材をまとめて購入する | 入力の単位は「食事」ではなく「買った食材」 |
