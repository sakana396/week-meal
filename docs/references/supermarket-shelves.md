# スーパーマーケットの売場分類・運営に関する参考資料

最終確認日: 2026-08-13

weekmeal の食材カテゴリを、食品成分表の分類ではなく「スーパーのどの売場で探すか」に近づけるための参考資料です。
ここに記載した分類をそのまま実装するのではなく、利用者が迷わず食材を見つけるための判断材料として使います。

## 先に分かったこと

- 日本の食品スーパーでは、青果・水産（鮮魚）・畜産（精肉）の生鮮3部門が基本になる
- そのほかに、惣菜・日配・一般食品（グロサリー）を分ける考え方が広く使われている
- 卵を「畜産」に入れる資料と「日配」に入れる資料があるなど、唯一の共通分類があるわけではない
- 実店舗では、商品そのものの種類だけでなく、温度帯、補充方法、加工場所、買い回り動線によって売場が分かれる
- weekmeal では厳密な業界分類よりも、「普段その商品を探しに行く棚」を優先した方がコンセプトに合う

## 業界で使われる基本分類

全国スーパーマーケット協会など3団体による年次統計では、次の分類が使われています。

| 分類 | 掲載されている商品例 |
|---|---|
| 青果 | 野菜、果物、花 |
| 水産 | 魚介、塩干物 |
| 畜産 | 食肉、肉加工品 |
| 一般食品 | 調味料、瓶缶詰、乾物、米、小麦粉、乾麺、嗜好品、菓子、酒 |
| 日配 | 豆腐、こんにゃく、納豆、練製品、佃煮、漬物、パン、卵、乳製品、生菓子、冷凍食品、アイス |
| 惣菜 | 惣菜、揚物、弁当、おにぎり、寿司、店内ベーカリー、ファーストフード |
| 非食品 | 日用雑貨、医薬・化粧品、家具、家電、衣料、文具、玩具 |

出典:

- [2023年 スーパーマーケット年次統計調査報告書（商品カテゴリー分類は5ページ）](https://super.or.jp/wp/wp-content/uploads/2023/10/nenji2023.pdf)
- [2025年 スーパーマーケット年次統計調査報告書・詳細版](https://www.super.or.jp/wp/wp-content/uploads/2025/10/2025nenji-tokei-detail.pdf)
- [スーパーマーケット統計調査（月次）](https://www.super.or.jp/?page_id=2646)

日本チェーンストア協会の販売統計では、食品を農産品・畜産品・水産品・惣菜・その他食品に分類しています。こちらでは鶏卵を畜産品に含めており、年次統計の日配分類とは異なります。

- [日本チェーンストア協会・チェーンストア販売統計の商品分類](https://www.jcsa.gr.jp/public/statistics.html)

この違いからも、アプリにとって重要なのは「正式な唯一の分類を再現すること」ではなく、一貫した分かりやすい棚を作ることだと判断できます。

## 商品マスターの詳細分類

GS1 JapanのJICFS/IFDBは、JANコード商品を企業横断で扱うための商品情報データベースです。JICFS分類には、食品・日用品などの大分類と、加工食品、生鮮食品、菓子、飲料・酒類などの中分類、その下の細かな商品分類があります。

加工食品やレシートの商品名を将来分類するときの参考になります。ただし、分類は非常に細かいため、weekmeal の画面へそのまま出す用途には向きません。

- [GS1 Japan・JICFS/IFDBの概要と最新版分類資料](https://www.gs1jp.org/database_service/jicfsifdb/)
- [JICFS分類選択のヒント](https://www.gs1jp.org/database_service/gjdb/data/index_jicfs_hint.html)

## 実際の店舗部門・配置例

### 実店舗のフロアガイド

スーパービックハヤシのフロアガイドでは、生鮮を青果・鮮魚・精肉の3部門に分け、ほかに惣菜・生寿司、日配、常温食品・雑貨、飲料・酒類を設けています。日配を鮮魚と青果の間、常温食品を店内中央、飲料・酒類を出口近くに置く例も説明されています。

- [スーパービックハヤシ・フロアガイド](https://www.big-hayashi.com/floor-guide/)

### 店舗の組織例

オーケーでは店舗部門を、青果・水産・精肉・グロサリー・総菜・ベーカリー・レジに分けています。実店舗の棚分類は、従業員の担当部門や加工業務とも結びついています。

- [オーケー・店舗と部門の紹介](https://s.recruit.ok-corporation.jp/guide/)

### 売場レイアウトに関する補助資料

小売業向けシステム会社テスクの記事では、入口付近の青果、外周の鮮魚・精肉・惣菜・日配、中央棚の一般食品という典型例と、短時間で必要な商品を見つけられる視認性の重要性が説明されています。これは公的基準ではなく、売場設計の実務的な解説として参照します。

- [テスク・スーパーマーケットのレイアウトの工夫](https://www.kktisc.co.jp/column/8777/)

## 公的な「食料品スーパーマーケット」の定義

日本標準産業分類では、食料品スーパーマーケットを、主として生鮮食料品（青果・鮮魚・精肉）を扱い、セルフサービス方式で販売する業態と説明しています。生鮮3部門がスーパーらしさの中心にあることを確認する資料として使えます。

- [e-Stat・日本標準産業分類 5811 食料品スーパーマーケット](https://www.e-stat.go.jp/classifications/terms/10/04/5811)

## weekmealで採用する棚

業界分類をそのまま使わず、利用者がスーパーで別の売場として認識する感覚を優先し、次の棚で進めます。

| アプリ上の棚 | 主な対象 |
|---|---|
| 野菜 | 野菜、きのこ、いも |
| 果物 | 果物 |
| 魚 | 生魚、刺身、干物、魚介 |
| 肉 | 牛、豚、鶏、ひき肉、肉加工品 |
| 卵 | 鶏卵、うずら卵など |
| 豆腐・納豆 | 豆腐、納豆、油揚げなど |
| 乳製品 | 牛乳、ヨーグルト、チーズなど |
| 米・パン・麺 | 米、パン、うどん、そば、パスタなどの主食 |
| 惣菜 | 唐揚げ、フライ、弁当、寿司、調理済み食品 |
| 冷凍食品 | 食品成分表で冷凍と明記された食品 |
| 飲み物 | 食品成分表に収録されている茶、コーヒーなど。未収録の商品は追加しない |
| お菓子 | 菓子類 |
| 調味料 | 調味料、香辛料 |
| その他 | 上記の棚に分類されない食品 |

検討時の原則:

1. 栄養学上の分類より、利用者が商品を探す売場を優先する
2. カテゴリの大きさを揃えるために、感覚の異なる棚を無理に統合しない
3. 上記の棚に分類されない食品は「その他」にまとめる
4. 同じ商品が複数の棚に見える場合は、一般的に探し始める棚を採用する
5. 将来のレシート入力では、JICFSなどの詳細分類を画面用の棚へ変換する
