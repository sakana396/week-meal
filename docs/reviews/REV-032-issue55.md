## 確かめられたこと

- `balanceTone` は E-49・DES-COL-01 どおり（high は紫 `#d8b4fe`、ok・unknown は色なし、low は `rgb(255, round(255·t), 0)`）。「不足」「過剰」「適正」「不明」の文字は残る
- 栄養詳細の棒・値・帯の状態ごとの色は消え、中立の灰色になった（レビュアーがスクリーンショットで確かめた）
- コントラスト比は WCAG 2.2 の相対輝度の式で、全 257 色（赤〜黄の 256 色と紫）を検査している。最小 5.252（赤）、最大 19.556（黄）、紫 11.879 をレビュアーが手計算で確かめた。強制カラーの E2E もある（NFR-07）
- `lowerTargetRatio` は再実装せず使っている。異常値のテストの名前を TC-FR-BAL-07-07 に移した（REV-029 #1 の申し送り）
- CSS の変更は BalancePanel と栄養詳細のクラスだけで、ほかの画面の見た目は変わらない
- 検証コマンド 5 つと E2E が成功
