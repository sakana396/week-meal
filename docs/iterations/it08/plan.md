# 反復 8 計画書: 貼り付けと食材一覧の改善

- 文書 ID: IT08-PLAN
- 版: 0.1（範囲は E-144〜E-149。要求への当てはめ、仮説、完了条件などの文はエージェントの書き起こしで、本人はまだ確かめていない）
- 作成日: 2026-11-24
- 期間の目安: 1〜2 週間

## 1. 目的

IT07 の実地検証で見つかった改行のない貼り付けと、残っていた読み取りの書き方に対応する。登録が少ないときの判定に案内を加え、スマートフォンで食材の登録・一覧を使いやすくする（E-144〜E-149）。

## 2. 確かめたい仮説

| ID | 仮説 | 確かめ方 |
| --- | --- | --- |
| H-19 | 改行のない「名前,量」の組や選ばれた書き方を読み取ると、貼り付け後の手直しが減る | 対象の入力をテストし、機会があれば本人の実際の買い物でも手直しを記録する |
| H-20 | 登録が少ないときの案内で、判定が登録した食材に基づくことが伝わる | 案内の条件と表示をテストし、本人に分かりやすさを聞く |
| H-21 | ホームの食材を 1 行に詰めると、スマートフォンで一覧を見渡しやすく、操作もしやすくなる | スマートフォン幅で表示と操作を確かめ、本人に使い心地を聞く |

仮説と確かめ方はエージェントの提案。実際の買い物で試せなければ、その結果は未検証とする。

## 3. 対象の要求

| 区分 | 要求 | 内容 |
| --- | --- | --- |
| 貼り付け | FR-RCP-01・02・05・06 | 空白で並ぶ「名前,量」の組を分けて読み、外部 AI 向け指示文でも改行を強く求める。分数＋単位、行頭の「•」、ml、負の数に対応する（E-145・E-148） |
| 判定の案内 | FR-BAL-09 | 登録した品数が少ないときに案内を出す。判定自体は変えない（E-146） |
| 食材の登録・一覧 | FR-UI-10、FR-UI-03 | ホームの食材を 1 行に詰め、細かい操作は行を押して開く。スマートフォンでの登録・一覧の操作を対象とする（E-144・E-147・E-149） |

品数の境目、ml から g への換算、負の数の扱い、1 行の具体的な配置は設計で決める。FR-BAL-05 の判定しない条件は変えない。
