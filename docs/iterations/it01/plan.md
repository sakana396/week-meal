# 反復 1 計画書: 計算の核とデータ

- 版: 0.3（承認）

- 期間の目安: 1〜2 週間

## 1. 目的

製品の核である「個数でざっくり入れた食材から、1,000 kcal あたりの割合で偏りを判定する」計算が、実際の買い物で実感と合うかを、最小の実装で確かめる。あわせて、以降の反復で使う開発基盤（テスト・lint・CI）を整える。

## 2. 確かめたい仮説

| ID | 仮説 | 確かめ方 |
|---|---|---|
| H-01 | 1,000 kcal あたりの割合と食事摂取基準の比較で、買った食材の偏りが実感と合う形で出る | 本人の直近 2〜3 回の実際の買い物を入れ、判定（不足・過剰）が実感と合うかを振り返りに記録する |
| H-02 | 目安重量がざっくりでも、判定の結果は大きく変わらない | 目安重量を ±30% ずらしたときに、判定が変わる栄養素の数をテストで調べる |
| H-03 | 絞り込んだ食品データで、普段の買い物の 9 割以上が一覧から見つかる | H-01 の買い物の品目のうち、一覧にあった割合を記録する |
| H-04 | 主食をエネルギー比（小 30%・中 40%・大 50%）で足す方式で、判定が自然になる | 主食の盛りを変えたときの判定の変化を記録する |
