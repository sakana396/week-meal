# 反復 9 計画書: 性能の再計測と食材行・貼り付けの仕上げ

- 文書 ID: IT09-PLAN
- 版: 0.1（本人の指示で作成、E-155。範囲は E-157。仮説、要求への当てはめ、完了条件などはエージェントの書き起こしで、本人はまだ確かめていない）
- 作成日: 2026-11-25
- 期間の目安: 1〜2 週間

## 1. 目的

IT08 の最終版で未計測の操作の性能を測り直し、食材行の操作の分かりやすさと読み上げ名を仕上げる。コンマの後に空白がある改行のない貼り付けにも対応する（E-155・E-157）。

## 2. 確かめたい仮説

| ID | 仮説 | 確かめ方 |
| --- | --- | --- |
| H-22 | 負荷のない状態で最終版を再計測すると、候補登録などの性能の状況が分かる | 対象操作を計測し、値と NFR-03 との関係を記録する |
| H-23 | 食材名の操作を分かりやすくし、同名行の操作を区別できるようにすると、食材行を操作しやすくなる | 表示と操作、読み上げ名の区別を検証し、本人に使い心地を聞く |
| H-24 | コンマの後に空白のある組を分けて読むと、貼り付け後の手直しが減る | 対象の入力をテストし、機会があれば本人の買い物でも手直しを記録する |

仮説と確かめ方はエージェントの提案。本人が試せない項目は未検証とする。

## 3. 対象の要求

### 3.1 実装・検証するもの

要求 ID への当てはめはエージェントが整理した。

| 区分 | 要求 | 内容 |
| --- | --- | --- |
| 性能 | NFR-03 | IT08 の最終版で測っていない候補登録などの操作を、ほかの作業を止めた状態で測り直し、結果を記録する（E-157）。日付の変更は対象外（E-153） |
| 食材行 | FR-UI-10、FR-UI-03 | 名前のボタンが押せると分かりにくい点と、開いた同名の行で削除などの読み上げ名が同じになる点に対応する（E-157、REV-083）。IF-03、IF-05、NFR-02 は満たしたままにする |
| 貼り付け | FR-RCP-05 | `豚肉, 1 鶏卵, 1` のようにコンマの後に空白がある組を分けて読むことに対応する（E-157、DES-IT08 9 章） |

計測の具体的な条件と回数は設計で決める。IT08 では同じ条件の最大値が 198.0 ms と 64.7 ms にぶれたことを踏まえる。ボタンの見た目、読み上げ名の文言、貼り付け時の空白の扱いの規則も設計で決める。
